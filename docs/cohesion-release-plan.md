# Kit cohesion and reliability release

Approved scope, 2026-11-02. Preserve the existing greeting preferences, stable
mobile navigation, experimental-only glass, and privacy-safe History.

1. Recover non-sensitive math work and manage explicitly saved graphs. Never
   automatically persist files, passwords, pasted documents or generated secrets.
2. Use one deterministic, accent-insensitive, ranked search across home and chrome.
3. Present reusable file results with download/share and bounded, local image
   handoffs (compress, convert, images to PDF).
4. Advance shared accessible overlays and field validation; organize Settings.
5. Add reviewed, allowlisted diagnostics and validated preferences transfer.
6. Establish production browser journeys and asset/interaction budgets, retaining
   the existing all-tool offline transaction gate.
7. Update release documentation, version and both-path production checks.

Physical iPhone/macOS installed-app checks are a release checklist, not something
desktop emulation can certify. Local browser access is disabled in this session;
browser tests must execute in CI rather than bypass that setting.
