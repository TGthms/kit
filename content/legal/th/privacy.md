# นโยบายความเป็นส่วนตัว

**อัปเดตล่าสุด:** 15 กรกฎาคม 2026

นโยบายนี้อธิบายวิธีจัดการข้อมูลเมื่อคุณใช้ **Kit** ซึ่งเป็นชุดเครื่องมือ��ี่เผยแพร่เป็นเว็บไซต์แบบสแตติกและออกแบบมาให้ทำงานในเบราว์เซอร์ของคุณ

## แนวคิดหลัก

Kit ได้รับการออกแบบให้ **การทำงานกับไฟล์ของคุณเกิดขึ้นบนอุปกรณ์ของคุณ** เราไม่ได้ให้บริการแอปพลิเคชันเซิร์ฟเวอร์ที่รับ จัดเก็บ หรือวิเคราะห์เนื้อหาของเอกสาร รูปภาพ หรือสื่อที่คุณเปิดในเครื่องมือ

## สิ่งที่ Kit ไม่ทำ

เมื่อคุณใช้เครื่องมือ (เช่น การรวม PDF หรือการบีบอัดรูปภาพ):

- ไฟล์ของคุณจะ **ไม่ถูกอัปโหลด** ไปยังแบ็กเอนด์ของ Kit เพื่อประมวลผล
- เรา **ไม่สร้างบัญชีผู้ใช้**
- เรา **ไม่ขายข้อมูลส่วนบุคคล**
- เรา **ไม่ใช้ SDK โฆษณาหรือการติดตามข้ามไซต์เพื่อโฆษณา**

## ข้อมูลที่อาจมีอยู่รอบบริการ

### 1. ข้อมูลที่ยังอยู่บนอุปกรณ์ของคุณ

เบราว์เซอร์ของคุณอาจจัดเก็บข้อมูลบางอย่างไว้ในเครื่อง เช่น:

- ค่ากำหนดรูปลักษณ์ (สว่าง มืด หรือตามระบบ)
- ภาษาที่เลือก
- เครื่องมือที่ชื่นชอบหรือปักหมุดไว้
- **สรุปประวัติการใช้งาน** (เครื่องมือที่ใช้ เวลาคร่าว ๆ คำอธิบายสั้น ๆ) — **ไม่ใช่** เนื้อหาไฟล์ของคุณ
- ค่าที่ตั้งไว้ล่วงหน้าที่คุณเลือกบันทึก

คุณสามารถล้างประวัติได้ใน Settings หรือลบข้อมูลของเว็บไซต์นี้ในเบราว์เซอร์

### 2. บันทึกเครือข่ายและโฮสติ้ง

โดยทั่วไป Kit โฮสต์เป็นไฟล์แบบสแตติก (เช่น บน GitHub Pages) เมื่อเบราว์เซอร์ของคุณร้องขอหน้าและทรัพยากร ผู้ให้บริการโฮสติ้งอาจบันทึกข้อมูลทางเทคนิคมาตรฐานโดยอัตโนมัติ เช่น ที่อยู่ IP user agent การประทับเวลา และ URL ที่ร้องขอ การบันทึกดังกล่าวอยู่ภายใต้โครงสร้างพื้นฐานและนโยบายของโฮสต์ ไม่ใช่เซิร์ฟเวอร์ของ Kit ที่เปิดเอกสารของคุณ

### 3. ทรัพยากรบุคคลที่สามที่เป็นตัวเลือก

ฟีเจอร์ขั้นสูงบางอย่างอาจโหลดไลบรารีประมวลผล (เช่น แกน FFmpeg WebAssembly หรือสคริปต์ PDF worker) จากเครือข่ายส่งเนื้อหาเมื่อคุณใช้งานครั้งแรก คำขอเหล่านี้อาจเปิดเผยข้อมูลเมตาเครือข่ายมาตรฐานต่อ CDN เนื้อหาไฟล์ของคุณยังคงประมวลผลในเบราว์เซอร์ ส่วน CDN ให้บริการโค้ด ไม่ใช่เอกสารของคุณ

### 4. อัตราแลกเปลี่ยน

เมื่อคุณรีเฟรชอัตราแลกเปลี่ยน เบราว์เซอร์นี้จะสอบถาม API สาธารณะของ Frankfurter คำขออาจแชร์ข้อมูลเมตาเครือข่ายมาตรฐาน เช่น ที่อยู่ IP user agent เวลา และ URL ที่ร้องขอ กับ Frankfurter อัตราอาจมาจากแคชของเบราว์เซอร์นี้และอาจล้าสมัย อัตราเหล่านี้เป็นข้อมูลอ้างอิงรายวันเท่านั้น ไม่ใช่การรับประกันสำหรับการซื้อขาย การบัญชี ภาษี หรือการชำระราคา

## Progressive Web App (PWA)

หากคุณติดตั้ง Kit หรืออนุญาตให้ใช้งานแบบออฟไลน์ service worker อาจแคช **เปลือกแอปพลิเคชัน** (หน้า สคริปต์ สไตล์ และไอคอน) Kit ไม่ได้ออกแบบมาเพื่อจัดเก็บไฟล์ส่วนตัวของคุณไว้ในแคชนั้น

## เด็ก

Kit เป็นเครื่องมือสำหรับการใช้งานทั่วไป ไม่ได้มุ่งเป้าไปที่เด็กอายุต่ำกว่า 13 ปี และเนื่องจาก Kit ไม่มีบัญชีผู้ใช้ เราจึงไม่เก็บข้อมูลส่วนบุคคลของเด็กโดยเจตนาผ่านระบบลงทะเบียน

## การเปลี่ยนแปลง

เราอาจอัปเดตนโยบายนี้เมื่อผลิตภัณฑ์หรือข้อกำหนดทางกฎหมายเปลี่ยนแปลง โดยจะปรับวันที่ “อัปเดตล่าสุด” เมื่อดำเนินการดังกล่าว การใช้ Kit ต่อหลังจากมีการอัปเดตหมายความว่าคุณได้ตรวจสอบนโยบายฉบับแก้ไขแล้ว
