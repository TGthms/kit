# Ketentuan Penggunaan

**Terakhir diperbarui:** 15 Juli 2026

Ketentuan ini mengatur akses dan penggunaan Anda atas situs web dan alat **Kit** (“Layanan”). Dengan menggunakan Kit, Anda menyetujui Ketentuan ini. Jika tidak menyetujuinya, jangan gunakan Layanan.

## Apa itu Kit

Kit menyediakan utilitas berbasis browser untuk tugas sehari-hari terkait file dan teks. Pemrosesan dirancang untuk berjalan **di sisi klien**. Kit ditawarkan sebagai aplikasi web statis dan perangkat lunak sumber terbuka.

## Lisensi perangkat lunak

Kode sumber Kit tersedia berdasarkan **Lisensi MIT**. Lisensi tersebut mengatur redistribusi dan penggunaan kode. Ketentuan ini mengatur penggunaan situs yang di-host dan Layanan online.

Alat audio dan video memuat mesin FFmpeg WebAssembly (`@ffmpeg/core`) berlisensi **GPL-2.0-or-later** (codec H.264 dan LAME MP3). Mesin disajikan dari situs ini dan berjalan di peramban. Kit tidak mengirim media Anda ke server. pdf.js dan pustaka lain tetap Apache, BSD, atau MIT. Jika Anda mendistribusikan ulang Kit bersama mesin FFmpeg, patuhi GPL mesin itu.

## Penggunaan yang dapat diterima

Anda setuju untuk tidak menggunakan Kit untuk:

- Melanggar hukum yang berlaku
- Melanggar kekayaan intelektual atau hak privasi orang lain
- Mencoba mengganggu, membebani secara berlebihan, atau membahayakan infrastruktur hosting
- Menyatakan Kit secara keliru sebagai layanan yang menyimpan atau mengirimkan file Anda kepada kami untuk diproses, padahal tidak demikian

Anda bertanggung jawab sepenuhnya atas file dan konten yang Anda proses dengan Kit serta kepatuhan terhadap hukum yang berlaku atas konten tersebut.

Hasil alat disediakan hanya untuk kenyamanan. Hasil tersebut bukan nasihat hukum, keamanan, medis, atau profesional lainnya. Fitur seperti penutup visual pada halaman PDF mungkin tidak menghapus semua data yang mendasarinya — verifikasi hasilnya untuk penggunaan yang sensitif.

## Layanan dan tautan pihak ketiga

Kit dapat menautkan ke situs eksternal atau memuat pustaka pihak ketiga. Kami tidak bertanggung jawab atas konten, kebijakan, atau ketersediaan pihak ketiga.


Saat Anda menyegarkan kurs mata uang, browser ini meminta data dari API publik Frankfurter. Permintaan tersebut dapat membagikan metadata jaringan standar (seperti alamat IP, user agent, waktu, dan URL yang diminta) kepada Frankfurter. Kurs dapat berasal dari cache browser ini dan mungkin sudah kedaluwarsa. Kurs tersebut hanya data referensi harian, bukan jaminan untuk perdagangan, akuntansi, pajak, atau penyelesaian transaksi.
