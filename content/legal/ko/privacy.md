# 개인정보 처리방침

**최종 업데이트:** 2026년 7월 15일

이 정책은 정적 웹사이트로 게시되어 브라우저에서 실행되도록 설계된 유틸리티 모음인 **Kit**을 사용할 때 정보가 처리되는 방식을 설명합니다.

## 기본 원칙

Kit은 **파일 작업이 사용자의 기기에서 이루어지도록** 설계되었습니다. 도구에서 여는 문서, 이미지 또는 미디어의 내용을 수신, 저장 또는 분석하는 애플리케이션 서버를 운영하지 않습니다.

## Kit이 하지 않는 일

도구(예: PDF 병합 또는 이미지 압축)를 사용할 때:

- 파일은 처리를 위해 Kit 백엔드에 **업로드되지 않습니다**.
- 사용자 계정을 **만들지 않습니다**.
- 개인정보를 **판매하지 않습니다**.
- 광고 SDK나 광고 목적의 사이트 간 추적을 **사용하지 않습니다**.

## 서비스 주변에 존재할 수 있는 정보

### 1. 기기에 남는 데이터

브라우저는 다음과 같은 제한된 정보를 로컬에 저장할 수 있습니다.

- 화면 설정(라이트, 다크 또는 시스템 설정)
- 선택한 언어
- 즐겨찾기 또는 고정한 도구
- **기록 요약**(사용한 도구, 대략적인 시점, 간단한 설명) — 파일 내용은 **아님**
- 저장하기로 선택한 프리셋

설정에서 기록을 삭제하거나 브라우저에서 이 사이트의 데이터를 삭제할 수 있습니다.

### 2. 네트워크 및 호스팅 로그

Kit은 일반적으로 **Cloudflare Pages**(공식 사이트: trykit.pages.dev)에 정적 파일로 호스팅되며 GitHub Pages 백업이 있습니다. 브라우저가 페이지와 리소스를 요청하면 호스트가 IP 주소, 사용자 에이전트, 타임스탬프, 요청 URL과 같은 표준 기술 데이터를 자동으로 기록할 수 있습니다. 이러한 기록은 호스트의 인프라와 정책에 의해 관리되며, 문서를 여는 Kit 서버에 의해 관리되는 것이 아닙니다.

### 3. 선택적 타사 리소스

PDF 도구는 pdf.js 워커, 글꼴 및 관련 자산을 **이 사이트에서** 불러옵니다(앱에 포함). 오디오·비디오 도구는 FFmpeg WebAssembly 엔진을 **이 사이트에서** 불러옵니다. 파일 내용은 브라우저에 남으며, 해당 라이브러리는 애플리케이션 코드이지 문서를 보내는 곳이 아닙니다.

### 4. 환율

환율을 새로 고치면 이 브라우저가 Frankfurter의 공개 API에 요청합니다. 요청에는 IP 주소, user agent, 시간, 요청한 URL과 같은 표준 네트워크 메타데이터가 포함되어 Frankfurter와 공유될 수 있습니다. 환율은 이 브라우저의 캐시에서 제공될 수 있으며 오래되었을 수 있습니다. 환율은 일일 참고 데이터일 뿐이며 거래, 회계, 세금 또는 결제를 보장하지 않습니다.

## 프로그레시브 웹 앱(PWA)

Kit을 설치하거나 오프라인 사용을 허용하면 service worker가 **애플리케이션 셸**(페이지, 스크립트, 스타일, 아이콘)을 캐시할 수 있습니다. Kit은 개인 파일을 이 캐시에 저장하도록 설계되지 않았습니다.

## 아동

Kit은 일반적인 용도의 유틸리티입니다. 13세 미만의 아동을 대상으로 하지 않으며, 계정을 제공하지 않으므로 등록 시스템을 통해 아동의 개인정보를 고의로 수집하지 않습니다.

## 변경 사항

제품 또는 법적 요구사항이 변경되면 이 정책을 업데이트할 수 있습니다. 업데이트할 때 “최종 업데이트” 날짜를 수정합니다. 업데이트 후에도 Kit을 계속 사용하면 개정된 정책을 검토한 것으로 봅니다.
